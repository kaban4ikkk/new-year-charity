# 🎁 Новогодняя акция «Подари мечту»

Веб-приложение для благотворительного фонда, которое помогает организовать сбор подарков для детей к Новому году. Проект заменяет хаотичную рассылку фотографий писем в мессенджерах на удобную, структурированную платформу.

## 🌟 Основные возможности

* **Просмотр писем**: Карточки с фотографиями детских писем. Фото открываются в модальном окне, автоматически исправляется EXIF-поворот (вертикальные снимки не лежат на боку). Поддерживается загрузка как локальных файлов, так и ссылок из облачного хранилища.
* **Три варианта помощи**:
  * 💝 **Скинуть деньги на подарок** — открывается окно с кнопками перевода на Сбербанк и Т-Банк.
  * 🎁 **Скинуть деньги на общий сбор** — аналогичное окно для перевода в общий фонд.
  * 🛒 **Купить подарок самому** — анонимная форма (без ФИО), где нужно указать только телефон, службу доставки (Wildberries, Ozon, Яндекс, СДЭК, Авито), адрес ПВЗ и дату прибытия заказа.
* **Бронирование**: Если пользователь выбирает «Купить подарок самому», карточка блокируется, чтобы никто другой не купил его повторно.
* **Панель волонтёра (Админка)**: Скрытый раздел (доступ по паролю), где координаторы фонда могут:
  * Видеть список забронированных подарков и отмечать их получение.
  * **Добавлять новые письма**: загружать фото (автоматически сохраняется в Supabase Storage) и заполнять данные ребенка.
  * **Удалять письма**: с функцией умного поиска по имени или ID и подтверждением удаления из базы и облака.
* **Праздничный интерфейс**: Живой таймер обратного отсчета до Нового года (на JavaScript), анимация падающих снежинок и светящиеся гирлянды по углам экрана.
* **Адаптивный дизайн**: Светлая новогодняя тема, вынесенная в отдельный CSS-файл.

## 🛠 Технологический стек

* **Язык**: Python 3.12
* **Фреймворк**: Streamlit
* **База данных**: PostgreSQL (в облаке Supabase)
* **Файловое хранилище**: Supabase Storage (S3) для фотографий писем
* **ORM**: SQLAlchemy + psycopg2
* **Работа с данными**: Pandas
* **Работа с изображениями**: Pillow (PIL)
* **Хостинг**: Streamlit Community Cloud
* **Фронтенд-элементы**: HTML/JS (для таймера), CSS (для гирлянд и снежинок)
