# 🎁 Новогодняя акция «Подари мечту»

Веб-приложение для благотворительного фонда, которое помогает организовать сбор подарков для детей к Новому году. Проект заменяет хаотичную рассылку фотографий писем в мессенджерах на удобную, структурированную платформу.

## 🌟 Основные возможности

* **Просмотр писем**: Карточки с фотографиями детских писем. Фото открываются в модальном окне, автоматически исправляется EXIF-поворот (вертикальные фото не лежат на боку).
* **Три варианта помощи**:
  * 💝 **Скинуть деньги на подарок** — открывается окно с ссылкой на оплату.
  * 🎁 **Скинуть деньги на общий сбор** — аналогичное окно для перевода в общий фонд.
  * 🛒 **Купить подарок самому** — анонимная форма, где нужно указать только телефон, адрес ПВЗ Wildberries и дату прибытия заказа.
* **Бронирование**: Если пользователь выбирает купить подарок сам, карточка блокируется, чтобы никто другой не купил его повторно.
* **Панель волонтёра**: Скрытая вкладка (доступ по паролю), где координаторы фонда видят список забронированных подарков и могут отмечать их получение.
* **Адаптивный дизайн**: Светлая новогодняя тема, вынесенная в отдельный CSS-файл для удобства редактирования.

## 🛠 Технологический стек

* **Язык**: Python 3.12
* **Фреймворк**: Streamlit
* **База данных**: PostgreSQL (в облаке Supabase)
* **ORM**: SQLAlchemy + psycopg2
* **Работа с данными**: Pandas
* **Работа с изображениями**: Pillow (PIL)
* **Хостинг**: Streamlit Community Cloud
